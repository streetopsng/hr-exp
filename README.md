# HR in Startups: Fire Fighting or Building Rockstars?

An interactive executive culture experience featuring 25 real workplace scenarios. Detailing the strategic transition from reactive HR emergency management to building sustainable organizational systems where high performance is normal.

## Features
- 🧠 **25 Real Scenarios**: Covering pattern recognition, root causes, and actionable operational fixes.
- ⌨️ **Keyboard Navigation**: Use Left and Right arrow keys or spacebar to seamlessly progress through cards.
- 🎨 **Executive UI**: Clean, responsive, typography-focused design built with Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```
